# 🎬 Global Media Analysis Dashboard 

An interactive **Global Media Analysis Dashboard** built using **Microsoft Power BI** to analyze movie trends, ratings, popularity, genres, and release patterns. The project demonstrates the complete data analysis workflow—from data cleaning and transformation to modeling and visualization—using an interactive dashboard.

---

# 📌 Project Overview

This project demonstrates the complete data analysis workflow using **Microsoft Power BI**.

The raw movie dataset was cleaned and transformed using **Power Query**, modeled within Power BI, and analyzed using **DAX** measures and interactive visualizations to uncover meaningful insights into movie ratings, popularity, genres, and release trends.

The dashboard enables users to explore the dataset through multiple analytical views with interactive filters and navigation buttons.

---

# 🎯 Project Objectives

- Analyze movie ratings and popularity.
- Compare genre-wise movie distribution.
- Explore movie release trends over time.
- Study the relationship between popularity and user ratings.
- Build an interactive and professional Power BI dashboard.

---

# 📈 Key Insights

- The dataset contains approximately **9.5K movies**.
- The average movie rating is **6.44**.
- The average popularity score is **40.86**.
- Drama is the most represented genre.
- Most movies belong to the **Average** rating category.
- Movie releases increased significantly after the year **2000**.
- **2021** recorded the highest number of movie releases in the dataset.
